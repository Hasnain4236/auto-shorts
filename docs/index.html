auto-shorts

auto-shorts is a personal tool that produces short science and technology explainer videos for a single YouTube channel owned by its operator: CrazyFindings.

It uses the YouTube Data API to upload videos to that channel, and the YouTube Analytics API to read the channel's own performance statistics so future videos can improve. It is not offered to other users and does not access anyone else's YouTube account.

Every script is researched from cited public sources, fact-checked, and disclosed as AI-assisted on YouTube.
