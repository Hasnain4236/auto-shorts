This policy explains what information the __APP_NAME__ app ("the app") accesses through Google and YouTube, how it is used, stored and shared, and how access can be revoked. The app is operated by the owner of the CrazyFindings YouTube channel. Only that person uses it.

1. Information the app accesses

With the channel owner's permission, given on Google's consent screen, the app uses these Google OAuth scopes:

  • Manage your YouTube account (https://www.googleapis.com/auth/youtube): to upload videos to the owner's channel; set each video's title, description, tags, category, visibility and scheduled publish time; and read the channel's own list of uploads and their status.
  • View YouTube Analytics reports (https://www.googleapis.com/auth/yt-analytics.readonly): to read aggregated statistics for the channel's own videos, such as views, watch time, average percentage viewed, audience retention, likes, shares, comment counts and subscribers gained.

The app does not request or access Gmail, contacts, Drive, location, or any other Google data. It does not collect personal information about viewers. YouTube Analytics data is aggregated, so it doesn't identify individuals.

2. How the information is used

  • To publish the videos the app creates to the owner's own channel, and schedule when they go public.
  • To measure how those videos perform, so future videos can be improved (for example, which topics and opening lines keep viewers watching).

The information is not used for advertising, is not sold, and is not used to build profiles of any person.

3. Storage and security

  • The OAuth refresh token that lets the app act on the owner's channel is stored only as an encrypted secret in the owner's private GitHub repository settings and in the owner's own computer. It is never published.
  • Per-video statistics and the list of uploaded videos are stored in the owner's private GitHub repository.
  • Data is transmitted only over encrypted (HTTPS) connections to Google, YouTube and GitHub.

4. Sharing

Information received from Google APIs is not shared with, sold or transferred to any third party. No person other than the channel owner can view it.

__APP_NAME__'s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services

The app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

6. Retention, revoking access and deletion

After access is revoked, the app can no longer read or change anything on the channel. All stored tokens and statistics are deleted within 30 days, or sooner on request to the contact below.
